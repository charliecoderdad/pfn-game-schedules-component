Preview of the “Game Schedules v2” Discourse theme component. This page reproduces desktop/header.html, desktop/desktop.scss, and the render logic from javascripts/discourse/api-initializers/theme-initializer.gjs. It attempts to fetch the live schedule JSON from S3; if that is blocked (e.g. opened via file://), it falls back to embedded sample data. A box only appears when a sport has a game on or after today (, America/New_York).
